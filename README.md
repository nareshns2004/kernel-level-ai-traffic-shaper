# kernel-level-ai-traffic-shaper

> **Status: paused design prototype. Nothing works end to end yet.**

This repo is a skeleton for ML-driven flow classification and traffic shaping on
Linux ("KernelMind"): a netfilter kernel module, four eBPF programs, a CLI, a
REST daemon and a Python trainer/compiler. The structure is there, but none of it
has been built, loaded or measured as a working system. This page lists what is
actually present.

## What is here

| Path | Contents |
|------|----------|
| `kernel/` | Netfilter module: 5-tuple flow table, feature extraction, a tree-walk "inference" over a placeholder model, policy, netlink, `/proc` |
| `ebpf/` | Four eBPF programs (`tc_classifier`, `inference_prog`, `flow_maps`, `feedback`) and a stub `vmlinux.h` |
| `userspace/` | `kernelmind` CLI, `kmshaperd` daemon with a small HTTP endpoint, Python SDK stubs |
| `ai/` | Trainer, quantiser and GBDT-to-BPF compiler scripts, model schema |
| `tests/` | KUnit tests (constants and struct sizes), pytest checks (JSON schema), benchmark scaffolding |
| `config/`, `scripts/` | Example config, HTB setup and install scripts |

## Known status

| Component | State |
|-----------|-------|
| Kernel module | Does not compile: `MODULE_VERSION` define clashes with the kernel macro; `monitor_only` is `static` in one file and `extern` in another |
| eBPF | 2 of 4 programs compile. `inference_prog` uses signed modulo (rejected by the BPF backend) and a non-existent context type; `tc_classifier` needs a real `vmlinux.h` and parses IP at offset 0 instead of after the Ethernet header |
| CLI | Does not compile: netlink command constants live in a kernel-only header |
| "AI" model | Never loaded. The built-in placeholder classifies every flow as class 3 (STREAMING), priority 252. The trainer's `fit()` ignores its data |
| Shaping | None. `tc_integration.c` only logs; the hook sets `skb->mark` and drops "anomaly" flows |
| Tests | Check constants, struct sizes and JSON schema only; no datapath tests |
| Benchmarks | None have been run. There are no performance numbers for this project |

Known runtime bugs that would matter once it builds: non-`_bh` spinlock shared
between softirq and process context (deadlock), RCU readers mixed with
non-RCU writers (use-after-free), no flow expiry, `skb->mark` overwritten on
every packet, and no `CAP_NET_ADMIN` check on the netlink handler.

## Direction, if it resumes

The kernel module is deprecated. A rewrite would be eBPF only, at tc
(`clsact`) egress, loaded with libbpf skeletons:

1. Generated `vmlinux.h`; every BPF object compiles and passes the verifier in CI.
2. tc classifier with an LRU flow map, a depth-limited tree in a double-buffered
   array map, `skb->priority` (not `mark`), EDT pacing into `fq`, fail-open.
3. libbpf loader with atomic model hot-swap; a real scikit-learn GBDT trainer with
   a parity test against the in-kernel result.
4. Network-namespace integration tests; benchmark results generated by script,
   recording kernel, CPU and NIC.

## Building

Do not load anything from this repo on a real machine. The existing `Makefile`
targets (`make ebpf`, `make userspace`, `make test`) are kept for reference and
currently fail as described above.

```bash
git clone https://github.com/nareshns2004/kernel-level-ai-traffic-shaper.git
cd kernel-level-ai-traffic-shaper
```
